# SoulForge Backend

Бэкенд для игры "Кузница скидок" на Go с MongoDB.

## Особенности

- **Система крафта с риском**: Улучшение материалов с вероятностью успеха
- **Ежедневные награды**: Бонусы за ежедневный вход с системой стриков
- **Сезонный пропуск**: Уровни, опыт и задания
- **Подписки**: Премиум функции для подписчиков
- **Интеграция с Xsolla**: Подготовлено для интеграции с платежной системой
- **Безопасность**: Хеширование паролей, JWT аутентификация

## Установка и запуск

1. **Установка зависимостей:**
```bash
cd backend
go mod tidy
```

2. **Настройка переменных окружения:**
```bash
cp .env.example .env
# Отредактируйте .env с вашими настройками
```

3. **Запуск MongoDB:**
```bash
# Убедитесь, что MongoDB запущена на localhost:27017
mongod
```

4. **Запуск сервера:**
```bash
go run main.go
```

## API Эндпоинты

### Аутентификация
- `POST /api/v1/register` - Регистрация
- `POST /api/v1/login` - Вход
- `GET /api/v1/profile` - Профиль пользователя

### Инвентарь
- `GET /api/v1/inventory` - Получение инвентаря
- `POST /api/v1/inventory/daily-reward` - Получение ежедневной награды
- `GET /api/v1/inventory/history` - История крафта
- `GET /api/v1/inventory/items` - Купленные предметы

### Крафтинг
- `POST /api/v1/crafting/upgrade` - Улучшение материалов
- `GET /api/v1/crafting/recipes` - Получение рецептов
- `POST /api/v1/crafting/item` - Крафт предмета

### Сезонный пропуск
- `GET /api/v1/season` - Информация о сезонном пропуске
- `GET /api/v1/season/rewards` - Доступные награды
- `POST /api/v1/season/claim` - Получение награды
- `GET /api/v1/season/quests` - Задания

## Механика игры

### Система улучшения материалов
- **Серый → Зеленый → Синий → Фиолетовый → Золотой**
- **10 материалов = 100% шанс успеха**
- **Меньше материалов = меньший шанс (10% за каждый)**
- **При провале - кэшбэк материалами предыдущего уровня**

### Ежедневные награды
- **Базовые**: 3 серых, 1 зеленый камень, 50 валюты
- **Бонусы за стрик**: каждые 7 дней + синий камень
- **Пропуск дня** - сброс стрика

### Сезонный пропуск
- **100 уровней** с увеличивающимся опытом
- **Бесплатные и премиум награды** за каждый уровень
- **Ежедневные и недельные задания** для получения опыта

## Интеграция с Xsolla

Бэкенд подготовлен для интеграции с Xsolla:
- Хранение информации о подписках
- Модели для виртуальных предметов
- API для обработки покупок

## Безопасность

- Пароли хешируются с использованием bcrypt
- JWT токены для аутентификации
- CORS защита
- Валидация входных данных

## Разработка

### Добавление новых рецептов
```go
// В controllers/crafting.go
newRecipe := models.ItemRecipe{
    Sku: "item_new_skin",
    Name: "Новый скин",
    Materials: map[models.Rarity]int{
        models.Gold: 5,
        models.Purple: 10,
    },
    CurrencyCost: 1000,
    RequiresSubscription: false,
}
```

### Добавление новых заданий
```go
// В models/season.go
newQuest := Quest{
    QuestID: "daily_purchase",
    Description: "Совершить покупку",
    Type: "purchase",
    Target: 1,
    Reward: QuestReward{
        Currency: 200,
        Experience: 300,
    },
}
```
